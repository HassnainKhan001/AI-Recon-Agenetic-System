# 🤖 AI Recon Agent (v1.0-SOC)

An autonomous multi-pillar attack surface intelligence dashboard built with AI.



## 🚀 What can it do?
Just type a natural language command like *"Run full recon on tesla.com"* and it executes 7 pillars:
- Subdomain Enumeration
- Cloud Bucket Hunting
- Service Fingerprinting
- SSRF & Metadata Engine
- Google Dorks & OSINT
- GitHub Secret Exposure
- DNS Intelligence

## ⚙️ Installation
1. Clone the repo: `git clone https://github.com/yourusername/ai-recon-agent.git`
2. Install dependencies: `pip install -r requirements.txt` (ya `npm install`)
3. Set up `.env` file with your API keys.
4. Run the app.
